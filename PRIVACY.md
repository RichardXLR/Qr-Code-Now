# Política de privacidade — QR Code Now

Última atualização: 28 de agosto de 2026.

O QR Code Now processa câmera, imagens e QR Codes localmente no aparelho. Não há servidor, cadastro, anúncios, analytics, rastreadores ou sincronização. O aplicativo não solicita permissão de internet.

O histórico e os favoritos ficam no banco privado do aplicativo até que o usuário os exclua. Backup em nuvem e transferência automática dos dados estão desativados.

Imagens são acessadas pelo Photo Picker do Android, sem acesso amplo aos arquivos. QR Codes gerados só são gravados em `Pictures/QR Code Now` quando o usuário toca em Salvar ou Compartilhar.

Links, mapas, discador, SMS e e-mail são entregues a aplicativos externos escolhidos pelo Android. Links HTTP/HTTPS suspeitos não são abertos automaticamente. A permissão de dispositivos Wi-Fi próximos só é pedida quando o usuário escolhe conectar uma rede lida e é declarada como não utilizada para localização.
